# Eres Remotion Showreel

Starter Remotion pour un showreel premium des composants Eres, basé sur le fichier Figma HeroUI Kit V3.

## Local

```bash
npm install
npm run studio
npm run render
```

## GitHub Actions

1. Pousser le contenu du repository.
2. Ouvrir l’onglet Actions.
3. Lancer `Render Eres Showreel` avec `Run workflow`.
4. Télécharger l’artifact `eres-showreel`.

Le projet contient des captures Figma de référence dans `public/figma/`. Elles servent de référence visuelle pour la reconstruction des scènes. Remplacer les polices et assets par les versions sous licence avant diffusion externe.
